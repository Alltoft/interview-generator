# Interview Question Generator — Design Spec
_Date: 2026-05-11_

## Overview

A studio-grade landing page + functional AI tool. Users enter a job title and receive 3 thoughtful, role-specific interview questions generated by Gemini. The page serves both as a polished product showcase and as the tool itself.

**Live audience:** Hiring managers, recruiters, and job seekers who want smart, tailored interview prep questions instantly.

---

## Tech Stack

| Layer | Choice | Reason |
|-------|--------|--------|
| Framework | Next.js 15 App Router | API routes for secure Gemini key, React for 21st Dev components |
| Styling | Tailwind CSS + CSS custom properties | Design tokens as CSS vars; Tailwind for layout |
| Animation | GSAP 3 + ScrollTrigger + SplitText | Pinned scrub, stagger, horizontal scroll |
| Smooth scroll | Lenis | Integrates cleanly with GSAP ScrollTrigger |
| AI | Google Gemini 2.0 Flash (via REST) | Free tier, generous limits, no card required |
| Hero image | Nano Banana | Generated at build time; served as static asset |
| Components | 21st Dev MCP | Steps, Card, Marquee pulled from registry |
| Hosting | Vercel | Zero-config Next.js deploy, edge network |
| Repo | GitHub | Public repo; URL submitted with live link |

## Page Architecture — 6 Sections

### 01 · Hero — `pinned-entry`
- Full-viewport (`100svh`). Background: Nano Banana generated image (abstract dark professional texture, obsidian + subtle gold grain), overlaid with 80% dark gradient.
- Nav: fixed, `INTRVW` wordmark left, `About` + GitHub icon right. Fades in after 0.3s.
- Headline: `"Ask the right questions."` — Playfair Display, 56–88px, italic. Animates in word-by-word via GSAP SplitText.
- Subhead: `"AI-generated interview questions for any role."` — Inter, muted, fades in after headline.
- Input field: single elegant text input, placeholder `"Customer Success Manager"`. Styled as underline-only on dark bg. Below it: `Generate →` button (white, full-width on mobile).
- Scroll indicator: thin animated line at bottom center.
- **ScrollTrigger:** pins the hero as §02 slides over the top of it.

### 02 · How It Works — `stagger-reveal`
- Background: `--c-surface` (#111).
- Eyebrow label: `"Simple by design"` — uppercase, letter-spaced, `--c-dim`.
- 3 steps in a horizontal row (stack on mobile):
  1. **Enter a role** — type any job title
  2. **AI generates** — Gemini crafts 3 tailored questions
  3. **Copy & use** — ready for your next interview
- Each step: large numbered circle (drawn via SVG on scroll), title, body copy.
- Connecting SVG line between steps draws itself (DrawSVG plugin).
- **ScrollTrigger:** each step + connector stagger-reveals as section enters viewport.
- 21st Dev `Steps` component as base.

### 03 · Generator — `sticky-panel`
- The functional tool section. Two-column layout on desktop: left = sticky form panel, right = scrollable results area.
- Form panel (sticky):
  - Label: `"Enter a job title"`
  - Large serif input field (Playfair Display, italic placeholder)
  - `Generate Questions →` primary button
  - Below button: small muted note `"Powered by Gemini"`
- Results area (right, scrolls):
  - Loading state: 3 skeleton cards (pulsing opacity animation)
  - Loaded state: 3 question cards, each animates in with `y: 30 → 0` stagger
  - Each card: question text (serif), thin top border, copy-to-clipboard icon
  - Error state: inline error message with retry option
- On mobile: stacked, form above results.
- 21st Dev `Card` component for question cards.

### 04 · Question Showcase — `horizontal-scrub`
- Eyebrow: `"Across every role"`
- Headline: `"Questions for every seat at the table."`
- 6 pre-generated role cards arranged horizontally. As user scrolls down, cards travel left.
- Roles: Customer Success Manager, Engineering Manager, Product Manager, UX Designer, Data Analyst, Marketing Lead.
- Each card: role title, 1 example question (serif italic), subtle border.
- **ScrollTrigger:** container pins, `x` translation scrubs from `0` to `-60%` over 200vh of scroll.
- 21st Dev `Card` as base.

### 05 · Role Marquee — `infinite-marquee`
- Full-width section, dark bg.
- Eyebrow centered: `"Works for any job title"`
- Two rows of job title pills:
  - Row 1: scrolls left at 40px/s
  - Row 2: scrolls right at 30px/s (opposite direction)
- ~20 diverse job titles per row, looped seamlessly.
- On hover: pill scales up 1.05, glow effect, row speed reduces to 10px/s.
- GSAP seamless loop (no ScrollTrigger — runs on RAF).
- 21st Dev `Marquee` component as base.

### 06 · Closing CTA + Footer — `fade-up`
- Minimal. Background: `--c-bg` (#121414). Hero image reappears at 8% opacity.
- Large italic serif quote: `"Your next interview starts here."`
- Single CTA button: `Generate Questions →` — links/scrolls to §03.
- Footer below: copyright, `Built with Next.js + Gemini`, GitHub link.
- **ScrollTrigger:** headline and button fade up on entry. Hero background cross-fades in via opacity scrub.

## API Design

### `POST /api/generate`

**Request:**
```json
{ "jobTitle": "Customer Success Manager" }
```

**Validation:** Strip tags, max 100 chars, non-empty.

**Gemini prompt:**
```
You are an expert interviewer. Generate exactly 3 thoughtful, behavioral interview questions for a {jobTitle} role. 
Return ONLY a JSON array of 3 strings. No preamble, no numbering, no extra text.
Example format: ["Question one?", "Question two?", "Question three?"]
```

**Response (200):**
```json
{ "questions": ["Q1?", "Q2?", "Q3?"] }
```

**Error responses:**
- `400` — missing/invalid jobTitle
- `500` — Gemini API failure (with user-friendly message)

**Security:** API key in `GEMINI_API_KEY` env var, server-side only. Input sanitized before interpolation.

## Error Handling

- Empty input → button disabled, no API call
- Gemini timeout (>10s) → error card with "Try again" button  
- Gemini returns malformed JSON → fallback parse attempt, then error state
- Network failure → error state with retry

---

## Privacy & Security

- No personal data in prompts — only the job title string
- API key never exposed to client
- Input max length enforced client + server side
- No logging of user inputs
